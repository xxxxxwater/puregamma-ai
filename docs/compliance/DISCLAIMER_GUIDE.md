# Disclaimer Guide

PureGamma AI must consistently disclose that product output is research, not financial advice.

## Required Default Disclaimer

Use:

```text
Users bear all risks of using this service. The service provider is not responsible for any AI-generated content.
```

## Where It Must Appear

- Daily market reports.
- Portfolio NAV briefs.
- Signals.
- Playbooks.
- Backtest outputs.
- iMessage, email, Telegram, and Slack investment messages.
- Product docs describing investment workflows.
- Public marketing pages that show example research.

## Extended Portfolio Disclaimer

Use where NAV or positions are shown:

```text
Portfolio NAV is an estimate based on available data. It is not tax advice, not financial advice, and not an official broker, custodian, or exchange statement.
```

## Extended Backtest Disclaimer

Use where backtests are shown:

```text
Backtests are hypothetical, depend on assumptions, and do not guarantee future results.
```

## Prohibited Claims

Do not claim:

- Guaranteed returns.
- Risk-free signals.
- Certain alpha.
- Tax accuracy.
- Official account statement status.
- Automated trade execution in the current MVP.

## Review Checklist

- Does the page mention investments, NAV, signals, or backtests?
- Does it include the relevant disclaimer?
- Does it avoid imperative trading language?
- Does it mark stale or partial data?
- Does it distinguish research from execution?
