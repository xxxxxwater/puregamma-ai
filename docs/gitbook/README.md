# PureGamma AI 使用手册
> AI 原生投研与决策支持平台 —— Beta(市场状态)/ Alpha(证据型机会)/ Long Gamma(期权凸性)
PureGamma AI 是面向活跃加密、股票与期权个人投资者的 AI 投研 SaaS。核心使用方式是「每日主动推送 + 组合感知研究 + 风险说明」:平台每天早上把市场情报与你的持仓风险整理成日报推送给你,你可以随时与 Agent、私人秘书对话深挖,也可以用回测实验室验证交易想法。
## 平台定位
- **研究软件,不是投顾**:平台不托管资产、不承诺收益、不自动执行真实交易。所有 AI 输出仅供研究参考,你需要独立决策并自担风险。
- **一个账户,全端通用**:Web 站(puregamma.ai)、Android、iOS、iMessage 使用同一账户与同一套数据。
- **Credits 计量**:AI 对话、报告生成、语音合成等按任务消耗 Credits,订阅套餐每月发放额度。
