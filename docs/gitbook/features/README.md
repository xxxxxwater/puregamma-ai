# 功能指南

PureGamma AI 的功能围绕「Beta / Alpha / Long Gamma」三层叙事组织:

- **Beta(市场状态)**:今天市场处于什么环境?——仪表盘、每日简报、市场情报
- **Alpha(证据型机会)**:有哪些值得研究的线索?——Agent 对话、研究报告、技能库
- **Long Gamma(期权凸性)**:如何用期权表达观点?——期权研究、财报 Gamma 候选
